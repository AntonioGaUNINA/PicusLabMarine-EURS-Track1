# PicusLabMarine, ENEA, UniNa — EURS Track 1, submission 19433

**Reported result:** Testing submission **19433**, user **2102**; Composite **0.731**, Q_seg **0.672**, mIoU **0.776**, F1 **0.867**, PSNR **29.69 dB**, SSIM **0.887**. This package reproduces this already uploaded submission, including its Full20 classifier. It excludes the later native6 classifier and joint-model experiments.

**Restoration.** Separate restoration and segmentation branches process each image independently. Condition-specific learned affine/quadratic spatial photometric inverses produce the restoration prior. For water-type suffix a<=4 a gated Restormer uses RGB, the original fractional input resize and the unclipped inverse. Other conditions use an adapted DRUNet and a fixed photometric blend. DepthAnythingV2 Small estimates relative depth from this same image. For 87 fixed conditions, a learned depth-conditioned forward model/noise bank drives three bounded Gauss–Newton posterior steps; other conditions keep the prior. FP64 posterior arithmetic preserves FP32 depth products and CPU repairs near quantization ties.

**Segmentation.** A separate R15 photometric image feeds two Marine DINOv3 ViT-L/16 + DPT models (256-channel features, 96-class native auxiliary heads, rank8 q/v LoRA, 5-class EURS heads); the background model also sees degraded RGB. Two Swin-L Mask2Former specialists contribute animal/background scores. The frozen fusion is 0.7 DINO / 0.3 Mask2Former with protected Other predictions. SAM3 support from fixed prompts `starfish`, `seahorse`, `sea turtle` refines Other with the historical factors 2.0 inside support and 0.5 inside unsupported boxes. Native-zero inputs skip SAM. Submission19433 additionally refits only the original positive EURS Conv2d256->5 classifier (1,285 parameters), with composed-score ground-truth NLL, AdamW lr1e-4, weight_decay0.0, 8 epochs on all20 training scenes and three fixed native degradation conditions per scene; the frozen encoder is unchanged. The selected head was chosen using training-phase internal holdout results, not Testing images.

**Training and public resources.** All20 EURS training scenes are used in the final refits. Native zero/constant images are excluded from training. The DRUNet final refit uses21 fixed epochs, 2,560 samples/epoch and 25% moderate RSUIGM-style physical augmentation; this is a verified approximation rather than an exact copy of the organizer renderer. Historical semantic training additionally uses **CoralscapesV2 train** (1,790 images) and **USIS16K train** (5,350 retained,82 excluded); duplicate/partial-overlap candidate screening and partial-label mappings are retained. Pretrained weights are Restormer blind color denoising, DRUNet, the public CoralscapesV2 DINOv3/DPT segmenter based on `facebook/dinov3-vitl16-pretrain-lvd1689m`, `facebook/mask2former-swin-large-ade-semantic`, DepthAnythingV2 Small, and Meta SAM3. Full state dictionaries, source identities/hashes, component epochs and data-screening scope are in `weights/MODEL_INDEX.json` after extracting the archive. No released Testing images were used for training, pseudo-label fitting, cross-image adaptation or parameter updates. Only fixed global choices between earlier submissions/settings were informed by leaderboard scores; the same fixed pipeline is applied to every image. No scene-name lookup or predictions cache is used.

**Exact offline inference.** The original NVIDIA H200 pipeline uses primary Torch2.6/CUDA12.4 and an isolated Torch2.10/CUDA12.8 SAM process. This is why the root Dockerfile supplies two runtimes; the usual Torch2.4 base is insufficient for this package. Models run eval/no-grad, seed2027; primary TF32 off and historical SAM TF32 on; neural forwards use their original FP32/BF16 policies. Input files are decoded one at a time; only trailing water-type/level indices are read. Longest-side1024 resizing, floating per-channel interpolation, uint8 rounding/truncation, final official resize helper and JPEG99/subsampling0/optimize are preserved; class masks are PNG IDs0–4. All weights/configs/tokenizer assets are local and runtime network is unnecessary. Five fixed fresh CUDA fixtures, including a renamed scene prefix and a native-zero input, match the actual19433 upload pixel-for-pixel for both decoded JPEG and mask. Observed peak primary GPU allocation9.48GiB plus isolated SAM3.81GiB; the test used H200, not a Jetson/RTX3090 certification. The combined process-tree peak RSS was9.45GB, below32GB. The new Dockerfile build and full1200-image re-run remain untested locally.
